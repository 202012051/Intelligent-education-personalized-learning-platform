## 📖 项目简介

随着大语言模型和知识图谱技术的快速发展，个性化教育已从传统的 "自适应题库" 走向 "智能学习伴侣"。本项目旨在打造一个面向**高等教育及职业教育**场景的智能学习平台，以编程类、理工科课程为切入点，通过深度理解学习者的认知状态、知识薄弱点和学习风格，为每位用户动态生成最优学习路径。

**核心目标：** 千人千面——每个学习者都有专属的学习路径规划。

## ✨ 核心功能

### 学生端

| 功能模块             | 描述                                         |
| -------------------- | -------------------------------------------- |
| 🎯 **学习仪表盘**     | 展示学习进度、当前路径、近期成绩及能力雷达图 |
| 📚 **课程学习页**     | 结构化课程内容浏览与学习                     |
| 🕸️ **知识图谱可视化** | 交互式知识点依赖关系图（ECharts 力导向图）   |
| 📊 **学习报告**       | 个人知识掌握情况分析与薄弱点诊断报告         |
| 📝 **初始测评**       | 新用户学习风格量表 + 知识状态评估问卷        |

### 教师端

| 功能模块           | 描述                             |
| ------------------ | -------------------------------- |
| 📈 **学情概览**     | 班级整体学习进度与能力分布可视化 |
| 🗂️ **课程内容管理** | 课程资源的增删改查（CRUD）       |

### 智能算法

| 模块             | 技术方案                                                     |
| ---------------- | ------------------------------------------------------------ |
| **知识图谱构建** | 基于课程大纲，定义知识点先修、包含、相关关系，存储为 JSON 结构 |
| **认知诊断**     | 简化 IRT（项目反应理论）模型，MVP 阶段规则引擎兜底           |
| **学习路径推荐** | 知识图谱 + 认知诊断结果，贪心策略（最短路径优先补薄弱点）    |
| **学习风格识别** | Felder-Silverman 模型，结合问卷与行为数据推断                |

## 🛠️ 技术栈

```
┌─────────────────────────────────────────────────────┐
│                     前端 (Frontend)                  │
│   React 18 + TypeScript + Ant Design + ECharts      │
├─────────────────────────────────────────────────────┤
│                     后端 (Backend)                   │
│        Spring Boot + MyBatis + JWT Auth             │
├─────────────────────────────────────────────────────┤
│                   算法服务 (Algorithm)               │
│          Python + scikit-learn + 规则引擎            │
├─────────────────────────────────────────────────────┤
│                   数据层 (Data Layer)                │
│              MySQL（持久化）+ Redis（缓存）           │
└─────────────────────────────────────────────────────┘
```

| 类别         | 技术选型              | 说明                                |
| ------------ | --------------------- | ----------------------------------- |
| 前端框架     | React 18 + TypeScript | 类型安全，多人协作友好              |
| UI 组件库    | Ant Design            | 中后台生态成熟，快速搭建            |
| 可视化       | ECharts               | 知识图谱可视化、学习进度图表        |
| 后端框架     | Spring Boot           | 快速开发，生态丰富                  |
| ORM          | MyBatis               | SQL 可控，便于性能调优              |
| 认证         | JWT                   | 无状态认证，后期预留 OAuth2.0 / SSO |
| 数据库       | MySQL                 | 主数据存储                          |
| 缓存         | Redis                 | 会话缓存、热点数据加速              |

| 知识图谱存储 | JSON 文件（MVP 阶段） | 降低基础设施复杂度，快速验证        |
| 前后端通信   | RESTful API           | 标准 HTTP 接口                      |
| API 文档     | Swagger / Apifox      | 前后端契约先行                      |
| 代码托管     | GitHub                | Feature Branch 工作流               |
| 测试         | JUnit + Jest + pytest | 后端/前端/算法全覆盖                |

## 🏗️ 架构设计

```
┌──────────────────────────────────────────────────────────┐
│                        客户端                            │
│          React SPA (学生端 / 教师端)                     │
└──────────────────────┬───────────────────────────────────┘
                       │ RESTful API
┌──────────────────────▼───────────────────────────────────┐
│                   Spring Boot 单体服务                    │
│  ┌─────────────┐ ┌──────────────┐ ┌───────────────────┐  │
│  │  用户模块   │ │  课程模块    │ │  推荐/诊断接口     │  │
│  └─────────────┘ └──────────────┘ └─────────┬─────────┘  │
│                                             │ HTTP        │
│  ┌──────────────────────────────────────────▼──────────┐  │
│  │              Python 算法服务                        │  │
│  │  认知诊断 | 学习路径推荐 | 学习风格识别             │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                           │
│  ┌─────────────┐           ┌─────────────┐               │
│  │   MySQL     │           │   Redis     │               │
│  │ (主数据库)  │           │  (缓存层)   │               │
│  └─────────────┘           └─────────────┘               │
└──────────────────────────────────────────────────────────┘
```

> **架构原则**：模块化单体优先，两周 MVP 不引入微服务，避免过度设计。

## 🚀 快速开始

### 环境要求

| 工具    | 版本要求 |
| ------- | -------- |
| Java    | 17+      |
| Node.js | 18+      |
| Python  | 3.9+     |
| MySQL   | 8.0+     |
| Redis   | 6.0+     |
| Maven   | 3.8+     |

### 1. 克隆仓库

```bash
git clone https://github.com/your-org/intelligent-edu-platform.git
cd intelligent-edu-platform
```

### 2. 后端启动

```bash
cd backend

# 修改数据库配置
vim src/main/resources/application.yml
# 设置 spring.datasource.url / username / password

# 初始化数据库
mysql -u root -p < sql/init.sql

# 启动服务
mvn spring-boot:run
# 默认端口 8080
```

### 3. 前端启动

```bash
cd frontend

# 安装依赖
npm install

# 开发模式启动
npm run dev
# 默认访问 http://localhost:5173
```

### 4. 算法服务启动

```bash
cd algorithm

# 创建虚拟环境
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 安装依赖
pip install -r requirements.txt

# 启动算法服务
python app.py
# 默认端口 8000
```

## ⚠️ 风险与应对

| 风险               | 影响                 | 概率 | 应对措施                                                |
| ------------------ | -------------------- | ---- | ------------------------------------------------------- |
| 算法效果不达预期   | 推荐不准，用户体验差 | 中   | 规则引擎兜底，保证基础可用性                            |
| 前后端联调时间不足 | 功能无法串联         | 中   | 提前定义 API 契约（Swagger），前后端并行开发            |
| 知识图谱数据质量差 | 推荐路径不合理       | 低   | 选定 1 门团队熟悉的课程（如 Python 基础），确保数据可控 |
| 某成员进度落后     | 整体延期             | 中   | 每日群内简短同步，及时调整任务分配                      |

## 📖 名词解释
